📊 Projeto Telecom X - Predição de Churn
🎯 Objetivo
Desenvolver um modelo de Machine Learning para prever a evasão de clientes (Churn) e identificar os principais motivos que levam ao cancelamento.

🛠️ Tecnologias Utilizadas
Python (Pandas, Numpy)

Scikit-Learn (Logistic Regression, Random Forest)

Matplotlib/Seaborn (Visualização de dados)

🧠 O que foi feito:
Tratamento de Dados: Conversão de JSON para DataFrame e limpeza de valores nulos.

Encoding & Normalização: Transformação de variáveis categóricas e escalonamento dos dados para modelos lineares.

Modelagem: Treinamento de Regressão Logística e Random Forest.

Análise Estratégica: Identificação das variáveis com maior impacto na decisão do cliente.
